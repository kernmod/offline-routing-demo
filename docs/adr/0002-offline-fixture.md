# ADR 0002: check in a small, reproducible offline fixture

- Status: accepted
- Date: 2026-08-31

## Context

The demo must start in airplane mode, build from public inputs, remain small
enough for an ordinary Git checkout, and prove that map and routing assets do
not depend on a private tile or graph service. A pointer to a mutable download
would weaken reproducibility; a city-scale production extract would make the
repository unnecessarily heavy.

## Decision

Check in a normalized, timestamp-pinned OpenStreetMap extract for a compact
Sydney CBD bounding box. Generate all runtime assets locally from it:

- a strict public walking-graph JSON contract;
- a valid PMTiles v3/MVT archive and local-only MapLibre style;
- a routing pack produced by the public Rust CLI;
- an asset manifest with sizes, SHA-256 digests, provenance, and a 5 MB cap.

The fixture generator is small and dependency-free. It implements only the
bounded feature set needed by this fixture (one line layer, no labels); it is
not presented as a general-purpose OSM tile compiler. Compatibility is checked
with the upstream PMTiles decoder and the Mapbox vector-tile decoder.

The exact `graph.json` contract is shared with the Rust pack builder. Routing
keeps the largest pedestrian component in bounds, emits both directions for
walking, and uses integer metre weights. Output ordering is explicit at every
boundary.

## Consequences

- A fresh clone can build the demonstration data without a data service.
- The map, graph, and pack can be regenerated byte-for-byte and audited.
- OSM provenance and ODbL obligations remain visible next to the fixture.
- The 5 MB cap prevents accidental growth or inclusion of unrelated datasets.
- The basemap is intentionally sparse and label-free; richer production maps
  remain out of scope.
- Refreshing the source is an explicit maintenance action that changes the
  snapshot and checksums and therefore requires review.

## Rejected options

- Download assets at first launch: violates airplane-mode first run.
- Reference a private CDN or graph builder: violates the public boundary.
- Commit a large regional PBF and production tile pipeline: obscures the demo
  and inflates clone/build time.
- Commit opaque binary assets without canonical source and checksums: cannot
  demonstrate provenance or reproducibility.
